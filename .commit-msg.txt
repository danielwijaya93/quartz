fix(android): request POST_NOTIFICATIONS and create high-importance alert channel

- nativePermissionHint() previously defaulted to "granted", so useNotifications
  never called requestNotificationPermission() on Android 13+.
- Query LocalNotifications.checkPermissions() on native mount, cache the real
  status in localStorage, and prompt when notifications are enabled and state is "default".
- Create a high-importance `quartz_alerts` notification channel and route
  turn-end, permission-request, and error alerts through it.
